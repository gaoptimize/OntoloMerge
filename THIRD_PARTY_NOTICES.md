## SUMO

The Suggested Upper Merged Ontology is provided by the SUMO project, including
the contributions and copyright holders named in its source files.
Project: https://www.ontologyportal.org  
Source repository: https://github.com/ontologyportal/sumo

The release contains an unmodified snapshot of the 145 KIF files, including domain, development, test, mapping and translation material, used
by this catalog and the original `README.txt`. File hashes and the snapshot revision
are in `PACKAGE_MANIFEST.json`. Existing headers and notices remain intact.

The original `Merge.kif` header credits the Institute of Electrical and Electronics
Engineers, Inc. and includes its terms. The upstream README credits Articulate
Software and Infosys and states GNU Public License terms. Consult those original
notices and each file's own header for the respective material.

The MIT license supplied for OntoloMerge code and mapping relations does not
replace the notices on upstream SUMO content.
